Programming foundations for distributed systems

Bismuth is a collection of Scala libraries and research prototypes for local-first and distributed software: replicated data types, reactive programming, data synchronization, and secure collaboration.

Get StartedTry the demosView on GitHub

Replicated Data Types

Compose conflict-free replicated data types from products and sums, with derived merge semantics.

Reactives

Signals and events in a transactional dataflow graph – the successor of REScala.

Replication & Channels

Exchange state over TCP, WebSockets, WebRTC, and more, on the JVM, JS, and Native.

Research Projects

Bismuth hosts the code of several research projects and their associated papers.

2024 – 2026

Byzantine Fault Tolerant Replication

BFTAccess Control

Replicated data types that remain consistent in the presence of malicious replicas, using hash DAGs and set reconciliation on bloom filters.

2025

Encrypted Replicated Data Types

CryptoRDTs

End-to-end encrypted replication of deltas between untrusted intermediaries.

2024

Delay-Tolerant Networking

ReplicationChannels

Replicated data types over delay-tolerant networks.

2023

LoRe: Local-First Reactive Programming

Lore

A programming model for local-first software that combines reactive programming with invariants, using verification to decide where coordination is necessary.

2023

Algebraic Replicated Data Types

RDTs

A systematic approach to conflict-free replicated data types by composing product and sum types, with automatically derived merge semantics.
